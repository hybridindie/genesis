# Epic Quality Pass (optional)

Read the Epic as a stakeholder deciding whether to fund it.

| Question | If no |
|---|---|
| Is there one outcome, stated in observable terms? | Split or restate the outcome |
| Are the 3–8 acceptance criteria checkable without reading the code? | Rewrite the weak criteria |
| Is the scope honest about what is out and why? | Add the exclusions |
| Does every story map to an AC or a named constraint? | Remove it or add the AC |
| Are the waves real — disjoint ownership, a contract first? | Fix the map |
| Are unknowns, contradictions, and owners visible? | Surface them |
| Can Wave 1 start today with no further questions? | Close the blockers |

## Report

- **Strong** — name the one or two things that make it reviewable.
- **Gaps** — what is missing, and the smallest change that fixes it.
- **Verdict (optional)** — Ready to decompose / Needs work / Blocked, plus the
  top three changes.

Do not score every section. The point is to make the next decision obvious.
